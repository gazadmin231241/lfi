## What to build

Неустранённые вердикты сужают фронт работы вместо повторения цикла. Пока
остаются раунды исправления, следующий раунд получает дословно только
замечания с вердиктом «не устранено» — множество открытых замечаний от раунда
к раунду может только уменьшаться, и граница раундов из конфигурации
превращается из единственной защиты в страховочный потолок. Когда раунды
исчерпаны, попытка отклоняется с итогом, перечисляющим каждое неустранённое
замечание вместе с обоснованием вердикта, — человек видит, что именно не
сошлось, без чтения логов агентов. Совещательные заметки верификатора,
не блокирующие приёмку, попадают в лог запуска, чтобы реальные наблюдения не
терялись.

## Acceptance criteria

- [x] При нескольких настроенных раундах второй раунд исправления получает
      только неустранённые замечания, дословно.
- [x] Замечание с вердиктом «устранено» не возвращается в последующие раунды
      ни в какой форме.
- [x] После исчерпания раундов итог попытки перечисляет неустранённые
      замечания с обоснованиями вердиктов в настроенном языке.
- [x] Совещательные заметки верификатора записываются в лог запуска и не
      влияют на приёмку.
