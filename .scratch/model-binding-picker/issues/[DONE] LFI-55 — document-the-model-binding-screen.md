## What to build

Человек, читающий README до первого запуска, понимает, что `lfi init` теперь
спрашивает модели экраном со стрелками, и что именно этот экран — способ
поменять модель потом.

Обе документации — английская и русская — описывают список из шести привязок,
показ разрешённого значения для унаследованных, пункт «— наследовать —»,
отдельный шаг маршрута для `dsh` и то, что `--model` и `--yes` экран
пропускают. Упоминание удалённого вопроса про рекомендуемый набор моделей
убирается, а сам набор описывается как предзаполненные значения списка.

Отдельно называется то, что экран не заменяет правку `.lfi/config.env` руками:
формат не изменился, и обе дороги ведут к одному файлу.

## Acceptance criteria

- [x] `README.md` и `README.ru.md` описывают экран привязок в разделе про
      `lfi init`.
- [x] Описаны наследование, пункт «— наследовать —» и показ разрешённого
      значения.
- [x] Описан шаг маршрута для `dsh`.
- [x] Указано, что `--model` и `--yes` пропускают экран и что без TTY он не
      показывается.
- [x] Упоминание вопроса про рекомендуемый набор моделей удалено из обеих
      документаций.
- [x] Оба документа описывают одно и то же поведение и не расходятся между
      собой.
